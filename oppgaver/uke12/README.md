<h2> Oppgaver for simulering av UDP-protokoll for sending av beskjeder fra klient til server  </h2>

* For å kjøre, 2 prosesser trengs
* 1 for server, 1 for klient

1. make all
2. ./oppgave2               (server)
3. ./udpclient_given 2023   (client, 2023 port)

eller

1. make all
2. ./oppgave1               (client)
2. ./udpserver_given 2023   (server, 2023 port)
